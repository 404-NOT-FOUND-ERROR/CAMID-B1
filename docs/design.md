# CAMID B1 互动内容设计说明

## 设计目标

让青少年从“这个东西像相机”转向“我能说出它为什么会动”。互动内容围绕可观察、可操作、可验证三个动作展开：

1. **可观察**：先用真实渲染和爆炸图建立零件地图。
2. **可操作**：用拖动、点击、拨动代替长段文字说明。
3. **可验证**：每个操作后都显示因果链，并把 CAD 已确认信息和教学推测分开。

## 视觉系统

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| Ink | `#07090D` | 深色章节、机构实验背景 |
| Paper | `#F3F1EB` | 浅色结构和路线章节 |
| Orange | `#F47721` | 操作焦点、编号、机械高亮 |
| Copper | `#C47740` | 齿轮、滚轮和金属结构 |
| Cyan | `#62D7D2` | Glass、Film 与光路高亮 |

标题使用大字号、紧字距的几何无衬线风格；导航采用黑色胶囊，延续 CAMID 网页参考中的品牌识别。

## 章节与知识关系

### 01 · Assembly map

载体是爆炸装配图和热点。目标是让学生把 `PrinterCase`、`Shutter Box/Case`、`Tank case` 与内部件对应起来，建立“装配层级”概念。

### 02 · Motion lab

载体是可调速的机构示意图。目标是理解输入、传递和输出：`CrankHandle → CrankShaft → Big gear / RollerGear → Roller → FilmExit`。这里的动画只表达结构上合理的教学方向。

### 03 · Light path

载体是快门圆盘和光线状态。目标是把 `Trigger`、`Wheel^Shutter`、`Shutter1/2/3` 和 `Glass` 放进同一个时序问题：什么遮挡光线，什么让光线通过。

### 04 · Material path

载体是 Tank 的侧剖视教学图。目标是把 `Film dimensions`、`Lever`、`lever support`、`Trap` 和 `FilmExit` 连接成材料路径。

### 05 · Your route

载体是四张路线卡片。目标是把一次完整操作拆成四个可独立加载的课堂内容单元：识别、传动、时序、输出。

## 交互原则

- 所有操作按钮都有文字标签，不依赖颜色单独传达含义。
- 关键状态使用 `aria-live` 更新，方便辅助技术读取。
- 动画尊重 `prefers-reduced-motion`。
- 页面可在窄屏堆叠布局，保持主要内容和操作可见。
- 运动实验不展示未经验证的尺寸、速度、齿数或曝光时间。
